# Learning distributed training

I'm learning how models train across GPUs. This repo is where I work through the questions with code, diagrams, and small experiments.

The commits build the model and work through its memory and compute requirements. The examples and checks are added as the code takes shape.

## Run the code

Install the project dependencies with `uv sync --locked`. The runnable examples appear under `why-distributed/` as they are added.
